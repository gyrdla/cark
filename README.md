# Dişli PWA — ilk prototip

## 

## Özellikler
- Proje/dişli türü: bitişli, sürekli, rutin
- Proje defteri: hedef, deadline, kaynaklar ve notlar
- Görevler: aktif süre, planlı gün/saat, deadline, tekrar, ön koşullar, paralel grup
- Genel bakış, ay/hafta/ajanda takvimi, dişli haritası, görev ve proje listeleri
- Planlama önerisi üretme ve kullanıcı onayıyla önerideki tarihleri uygulama
- JSON dışa aktarma/yedekleme
- Yerel cihaz depolaması; hesap veya bulut senkronizasyonu yok

## Sınırlar
Bu bir çalışan ilk prototiptir; gelişmiş otomatik zamanlama motoru değildir. Henüz çok kullanıcılı bulut senkronizasyonu, takvim sağlayıcılarıyla entegrasyon, tam kritik-yol hesabı, esnek çakışma optimizasyonu veya otomatik görev tekrarlarının yeni kayıtlar üretmesi uygulanmamıştır. Veriler tarayıcı/site verileri silinirse kaybolabilir; düzenli JSON yedeği alın.
